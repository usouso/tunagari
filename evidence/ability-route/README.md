# 能力の行き先（攻撃か防御か）の測り方 — 2026-11-14

本物の `rules.js` は変えていない。作業用のコピーに切りかえ（`s.__v`）を足して測った（`rules-switches.diff`）。

## 測り方（`route.js`）
- ボット（smart、ごほうびは でたらめ、5連戦 40周）が選んだ盤面で、能力ブロックが わたしているとき、盤面に攻撃も防御もある場面を集める。
- その能力の行き先だけを、盤面の別の攻撃・防御ブロックに付けかえて（形は無視）、1ターンの点（ボットの点）をくらべる。
- 「ほぼ同じ」＝ 攻撃の最良と防御の最良の差が1点未満。
- 「回数の目安」＝「自分のヒット数と敵のヒット数の、多い方に わたす」。差がある場面で、これが当たった割合。
- 「差の平均」は 40点で頭打ちにして平均（勝ち負けが決まる場面の 5000点を入れないため）。

## ほかに測ったもの
- 氷を「大きさ型」（のったヒットのダメージ・防いだダメージ ×氷の数字/4）にして、はじめのデッキの再生を氷に（`DECK=ice`、v=3）：
  氷のほぼ同じ 33%、回数の目安 39%、差の平均 2.3、攻撃48% / 防御52%。（同じデッキで今の氷（v=0）：36%、76%、2.0、51% / 49%）
- 同じ条件で、氷を受け取った札が増幅も受け取っていた割合（`couple.js`）：今 12% → 大きさ型 13%（ほぼ変わらない）。加速は 53% → 62%。
- はじめのデッキの再生→氷、毒1つ→毒消費（`DECK=time`、v=0）：全体で ほぼ同じ 42%、回数の目安 81%。毒消費は ほぼ同じ 75%。
